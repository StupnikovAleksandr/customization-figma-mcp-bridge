# Запуск Figma MCP Bridge и Playwright

Команды выполняются из корня проекта в PowerShell. Нужны Node.js 20+, npm, авторизованный Codex CLI и Figma Desktop.

## Установка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-figma.ps1
```

Скрипт устанавливает зависимости сервера, плагина и браузерных инструментов, проверяет типы плагина, собирает компоненты, устанавливает браузер и регистрирует MCP в настройках Codex. Перед изменением настроек создаётся резервная копия. Существующее подключение Playwright сохраняется, если уже настроено. После переноса папки повтори настройку: команды MCP используют абсолютные пути.

## Импорт manifest

Открой дизайн в Figma Desktop. В главном меню Figma или поиске команд найди **Plugins → Development → Import plugin from manifest…**. В браузерной Figma импорт development plugin недоступен. Выбери `figma-mcp-bridge/plugin/manifest.json`.

Запусти Figma MCP Bridge из development plugins и оставь его окно открытым. Импорт manifest сам по себе не подключает файл. Для нескольких файлов плагин запускается в каждом отдельно. [Документация Bridge](figma-mcp-bridge/README.md).

## Проверка подключения

Перезапусти Codex, открой его в корне проекта и выполни:

```powershell
codex mcp list
node .\verify-figma.mjs
```

Проверка запускает сервер Bridge и отдельный Playwright с пустой страницей. Она не подтверждает вход на dev-стенд. Попроси агента показать подключённые файлы Figma и выделение; затем открыть нужный сайт через настроенный браузерный MCP.

Выдели все нужные фреймы и состояния. Передай агенту URL и область проверки. Для закрытого стенда настрой [Basic Auth](browser-tools/BASIC-AUTH.md). Агент применяет [skill](skills/figma-site-audit/SKILL.md) и [стандарт отчёта](AUDIT-REPORT-STANDARD.md): реальные размеры фреймов, PNG 1×, допуск 3 CSS px включительно. Результаты сохраняются в исключённую из Git папку `audit-*/`.

## Диагностика

- Проверь `node --version`, `npm --version`, `codex --version` и результат установки.
- При пустом списке Figma проверь открытый дизайн, запущенный плагин и доступ локального соединения через защитное ПО.
- После пересборки перезапусти плагин; после изменения MCP перезапусти Codex.
- Для dev-стенда проверь VPN, URL, сертификат и ответ браузера. Ошибка сертификата и блокировка защитным ПО требуют отдельного исправления доверия или доступа.
- Обёртка Basic Auth заменяет команду Playwright; особые параметры прежнего подключения автоматически не переносятся.
