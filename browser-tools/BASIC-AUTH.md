# Dev-стенд с HTTP Basic Auth

## Один раз сохранить доступ

Открой PowerShell и выполни:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\browser-tools\configure-basic-auth.ps1
```

Введи логин и пароль в локальном окне. Пароль скрыт при вводе. Скрипт сохраняет учётные данные в `.local/dev-credential.xml`, зашифрованные Windows DPAPI: расшифровать их может текущий пользователь Windows на этом компьютере. Пароль не записывается в настройки MCP и не передаётся аргументом командной строки.

Скрипт создаёт резервную копию настроек Codex и заменяет подключение `playwright` запуском `start-playwright.mjs`. Остальные MCP-подключения сохраняются. Особые параметры прежнего Playwright (например, расширение или CDP) не переносятся. Новый браузер использует отдельную сессию в памяти.

После настройки полностью перезапусти Codex.

## URL указывается отдельно

Адрес можешь прислать позже в чате или указать в документе. Затем его нужно перенести в `browser-tools/.local/dev-site.json`:

```json
{
  "url": "https://dev.example.ru/about"
}
```

В локальном файле также можно указать поля `username` и `password` рядом с `url`. Если они присутствуют, Playwright использует их вместо зашифрованных учётных данных. В этом варианте пароль хранится в файле обычным текстом; `.local/` исключена из Git. Чтобы вернуться к Windows DPAPI, удали оба поля из JSON.

Basic Auth применяется только к origin этого адреса (`https://dev.example.ru`): схема, домен и порт должны совпадать. При смене домена обнови файл и перезапусти MCP/Codex. Переход на другой домен не получает эти учётные данные автоматически.

Если URL пустой, браузер запускается без Basic Auth. При указанном URL и недоступных учётных данных запуск останавливается с понятной ошибкой. Наличие настройки не подтверждает вход: после перезапуска попроси открыть конкретный URL, чтобы проверить ответ стенда. Если требуется VPN, включи его заранее.

## Обновить или отключить

- Для изменения DPAPI-доступов повтори команду настройки. Если username/password присутствуют в JSON, они имеют приоритет: обнови их отдельно или удали оба поля для перехода на DPAPI.
- Для отключения Basic Auth очисти значение `url` и перезапусти Codex.
- Для сохранения только учётных данных без изменения MCP добавь `-SkipRegistration` к команде настройки.
- Папка `.local/` исключена из Git. Не добавляй её в архивы для передачи другим людям.

Это настройка обычного HTTP Basic Auth (окно логина/пароля браузера, ответ сервера 401). Для входа через форму сайта или двухфакторной авторизации нужен отдельный сценарий.

## Поля рядом с URL

Для локального файла browser-tools/.local/dev-site.json допустим такой формат (используй собственные значения):

```json
{"url":"https://dev.example.ru/about","username":"YOUR_LOGIN","password":"YOUR_PASSWORD"}
```

Файл хранит пароль обычным текстом и исключён из Git. Само создание JSON не регистрирует обёртку MCP: выполни настройку выше и перезапусти Codex. Скрипт настройки сохраняет DPAPI-доступы, но не удаляет существующие поля JSON. Не запускай read-basic-auth.ps1 вручную для просмотра: его вывод предназначен для внутреннего чтения обёрткой.

Обычный HTTP Basic Auth не является отдельной версией «Basic 2»; если стенду нужен второй этап входа или форма авторизации, требуется отдельный сценарий. Общая установка: [FIGMA-START.md](../FIGMA-START.md).
